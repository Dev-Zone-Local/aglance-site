AtGlance CLI

Install or update the CLI agent

The CLI runs on each Linux host you want to watch. It backs up service configs and reports to your Management Console. Ubuntu or Debian with systemd and Python 3.8 or newer.

Installer

New installation. Downloads the latest package, installs it with its dependencies, and checks that atglance runs.

Download installer atglance-installer.sh
Or run it in one command
curl -fsSL https://app.atglance.live/cli/atglance-installer.sh | sudo bash

Updater

Update the CLI on a host where it is already installed. Your configuration and registration are kept.

Download updater atglance-updater.sh
Or run it in one command
curl -fsSL https://app.atglance.live/cli/atglance-updater.sh | sudo bash

Debian package

Prefer to install by hand? Download the .deb and install it with apt, which pulls in the dependencies. The same command also updates an existing install.

Download .deb atglance_latest_all.deb
Install or update
curl -fsSLO https://app.atglance.live/cli/atglance_latest_all.deb && sudo apt install -y ./atglance_latest_all.deb
Check the version
atglance --version

Register this host

Connect the host to your Management Console. You need the console address and an API token from the console.

  1. Save the console address and token.
sudo atglance --config-save
  1. Register the host with the console.
sudo atglance --system-register

No console yet? Install the Management Console first.

Before you start

  • Ubuntu 20.04+ or Debian 11+ with systemd, and Python 3.8 or newer.
  • Root or sudo on the host.
  • The host must reach your Management Console on port 8002 (CLI gateway).
  • Remove the CLI with sudo apt remove atglance.
