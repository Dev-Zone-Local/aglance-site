Get AtGlance running

AtGlance has two parts: the Management Console you host for your organization, and the CLI agent on each Linux server you want to watch. Pick what you need to install or update.

Management Console

Self-hosted web console and API, running in Docker. Install it once per organization.

How it fits together

  1. Get a licenceCreate one on your AtGlance dashboard and enter the emailed code.
  2. Install the consoleRun the console installer and paste the licence key.
  3. Add your serversInstall the CLI agent on each host and register it with the console.
