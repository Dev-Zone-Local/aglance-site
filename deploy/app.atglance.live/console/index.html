Management Console

Install or update the Management Console

Download the installer to set up a new Management Console, or the updater to move an existing one to the latest release. The installer asks for a licence key from your AtGlance dashboard.

Installer

New installation on Ubuntu, Debian, RHEL/Rocky/Alma, Amazon Linux or Fedora. Installs Docker if it is missing.

Download installer atglance-installer.sh
Or run it in one command
curl -fsSL https://app.atglance.live/console/atglance-installer.sh | sudo bash

Updater

Update an existing Management Console to the latest release. Your data and settings are kept.

Download updater atglance-updater.sh
Or run it in one command
curl -fsSL https://app.atglance.live/console/atglance-updater.sh | sudo bash

Installer

New installation on Windows 10/11 or Windows Server with Docker Desktop. Run PowerShell as Administrator.

Download installer atglance-installer.ps1
Or run it in one command (PowerShell)
irm https://app.atglance.live/console/atglance-installer.ps1 | iex

Updater

Update an existing Management Console on Windows to the latest release. Your data and settings are kept.

Download updater atglance-updater.ps1
Or run it in one command (PowerShell)
irm https://app.atglance.live/console/atglance-updater.ps1 | iex

Before you start

  • 2 vCPU, 2 GB RAM and 5 GB free disk.
  • Root or sudo (Linux) or Administrator (Windows), and internet access to Docker Hub and GitHub.
  • After install, open http://<server-ip>:8000 and finish the setup wizard.
  • Open port 8000 (console) and 8002 (CLI gateway). Keep 3306 and 6379 closed.
